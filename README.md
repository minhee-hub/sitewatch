# 건설현장 객체 인식 히트맵·위험판단

영상 파일이나 유튜브 주소에서 사람, 굴착기, 덤프트럭, 로더, 불도저, 크레인, 롤러, 콘크리트 믹서, 지게차를 찾고, 바닥 평면 기준으로 위험도와 앞으로 3초의 동선을 그립니다. 사람과 중장비가 가까워진 자리는 영상과 같은 화면 비율의 히트맵으로, 재생을 따라 최근 겹침이 진하게 남습니다.

이 결과는 유도자나 작업계획서를 대신하지 않습니다.

## 설치

Python 3.9 이상이 필요합니다.

```bash
pip install -r requirements.txt
```

실제 영상 분석을 처음 실행하면 YOLOE 가중치와 텍스트 인코더를 `models/`에 받습니다. GPU가 있으면 `yoloe-26s-seg.pt`, 없으면 `yoloe-11s-seg.pt`를 씁니다. CPU 기본 모델의 텍스트 인코더는 약 570MB이고, 이때 CLIP 패키지도 한 번 설치됩니다. 유튜브 주소는 `yt-dlp`로 재생 주소를 받습니다.

## 실행

```bash
streamlit run app.py
python cli.py video --source 현장영상.mp4 --calibration runs/calibration.json --output runs/video
python cli.py live --source "https://www.youtube.com/watch?v=영상ID" --calibration runs/calibration.json
python cli.py calibrate --source 현장영상.mp4 --output runs/calibration.json
```

화면에서는 영상 파일과 유튜브 주소를 고릅니다. 실시간 창은 `q`로 종료하고 `h`로 히트맵을 켜고 끕니다. 보정 창은 점을 찍은 뒤 `s`로 저장합니다.

## 거리 보정

미터 위험도는 바닥이 평면이라는 가정에서만 계산합니다. 보정 전에는 상자와 화면상 궤적만 보여주고, 픽셀 거리를 미터처럼 표시하지 않습니다.

네 점 호모그래피가 기본입니다. 첫 프레임에서 바닥의 직사각형을 **좌상, 우상, 우하, 좌하** 순서로 찍고 실제 가로·세로(m)를 넣습니다. 사람 발과 장비 접지점을 이 평면으로 보낸 뒤 거리를 재고, 위험 원과 예측 동선은 다시 영상 위로 그립니다.

두 점만 알면 그 사이 실거리로 배율을 만들 수 있습니다. 원근이 남아서 화면 가장자리는 어긋납니다. 고정 카메라에서 네 점을 쓰는 쪽이 맞습니다.

## 위험도

법령(산업안전보건기준에 관한 규칙 제200조, 제20조)은 운전 중인 차량계 건설기계에 부딪힐 장소와 굴착기 붐·암·버킷 선회 위험 장소의 출입을 금지합니다. 몇 미터인지 고정해 두지는 않았습니다. 안전보건공단 안내는 굴착기 작업반경이 통상 5–10m 이상이라고 설명합니다.

그래서 등급 경계는 `config/defaults.yaml`의 설정값입니다.

- 발밑 점은 사람·버킷 쪽은 분할 마스크의 가장 아래 점, 없으면 박스 하단 중앙입니다. 선회 장비의 원의 중심은 박스 하단 중앙이고, 거리는 그 중심과 마스크 하단 중 근로자에게 더 가까운 쪽을 봅니다.
- 이동 장비의 적색은 지면 윤곽 반지름 + 1.5m입니다.
- 황색은 적색에 정지거리를 더한 원입니다. 정지거리 = 속력 × 2.5초 + 속력² / (2 × 2.0). 감속 2.0m/s²는 승용차(약 3.4m/s²)보다 보수적입니다. 시속 10km이면 반응 약 6.9m, 제동 약 1.9m입니다.
- 굴착기와 크레인은 팔이 박스 밖으로 나가므로 작업반경을 적색으로 둡니다. 기본값은 굴착기 5m(인지 8m), 크레인 9m(인지 12m)입니다.
- 덤프트럭·로더·불도저·믹서의 인지 반경은 6m, 롤러·지게차는 5m입니다. 인지 반경 안이면 주의입니다.
- 적색은 위험반경 안, 충돌예상시간 1.5초 미만, 또는 1.5초 안에 예측 동선이 위험반경으로 들어올 때입니다.
- 황색은 정지거리 범위, 충돌예상시간 3초 미만, 또는 3초 안에 들어올 때입니다.
- 같은 근로자–장비 쌍이 경고 이상으로 올라갈 때만 사건 목록에 남기고, 적색으로 바뀌는 순간에만 경보음을 냅니다.

예측 동선은 바닥 좌표의 등속도 칼만 필터입니다. 과거 궤적은 실선, 3초 예측은 0.5초 간격의 점선, 3초 지점에는 불확실 타원을 그립니다. 검출이 흔들려 속력이 비현실적으로 커지지 않도록 15m/s에서 자릅니다.

겹침 히트맵은 인식이 끝난 영상과 같은 크기입니다. 사람과 장비가 주의·경고·위험으로 가까워진 구간을 둘 사이에 칠하고, 약 2.5초 동안 옅어져 재생 위치를 따라 움직입니다.

## 결과 파일

`runs/...` 아래에 다음이 생깁니다.

- `annotated.mp4` 인식 결과 위에 겹침 히트맵이 올라간 영상. 화면 비율은 원본과 같습니다. ffmpeg가 있으면 브라우저에서 재생되는 H.264로 다시 담습니다.
- `heatmap_overlap.png` 영상과 같은 크기의 겹침 히트맵
- `events.csv` 경고 이상으로 올라간 시각, 등급, 거리, 이유
- `summary.json` 최고 등급과 프레임 수. 결과 영상에는 위험반경 원을 그리지 않습니다.
- `calibration.json` 사용한 보정

## 한계

카메라 한 대와 평평한 바닥을 가정합니다. 굴착기 팔의 실제 각도는 재지 않고 작업반경 원으로 대체합니다. 가리거나 ID가 바뀌면 동선이 끊깁니다. 개방 어휘 검출은 현장 영상으로 다시 학습한 모델보다 틀릴 수 있어서, 다른 가중치를 쓰려면 `config/defaults.yaml`의 `model` 항목을 바꾸면 됩니다.
